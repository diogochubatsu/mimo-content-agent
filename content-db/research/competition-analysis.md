# Competitor Analysis - Import/Dropshipping Niche

**Date:** 2026-07-25

## Top 5 Competitors

### 1. ImportDojo
- **URL:** importdojo.com
- **Focus:** 1688/Alibaba sourcing guides
- **Content:** Tutorials, supplier lists, margin calculators
- **Strength:** Deep China knowledge
- **Weakness:** Dated content, limited language support
- **Traffic:** ~50k/month estimated

### 2. SoloImporter
- **URL:** soloimporter.com
- **Focus:** Solo importers, small business
- **Content:** Step-by-step guides, tool reviews
- **Strength:** Beginner-friendly
- **Weakness:** Limited to small-scale importers
- **Traffic:** ~30k/month estimated

### 3. AliTariffs
- **URL:** alitariffs.com
- **Focus:** Import tariffs, landed cost calculator
- **Content:** Tariff guides, calculator tools
- **Strength:** Unique tool (Chrome extension)
- **Weakness:** Narrow focus (tariffs only)
- **Traffic:** ~20k/month estimated

### 4. HiSourcing
- **URL:** hisourcing.com
- **Focus:** China sourcing guides
- **Content:** 1688 vs Alibaba comparisons, guides
- **Strength:** Real data from Yiwu
- **Weakness:** Agent-biased content
- **Traffic:** ~40k/month estimated

### 5. CNBuyPilot
- **URL:** cnbuypilot.com
- **Focus:** Shopping agents for 1688
- **Content:** Agent reviews, guides
- **Strength:** Comprehensive agent directory
- **Weakness:** Agent-focused, not buyer-focused
- **Traffic:** ~15k/month estimated

## Competitive Gaps (Our Opportunities)

1. **Multi-language content** - Most competitors are EN-only
2. **Real margin data** - Few show actual margin calculations
3. **Brazilian market focus** - Almost no PT-BR content
4. **Cross-platform comparison** - 1688 vs Alibaba vs AliExpress in one place
5. **Fresh data** - Many competitors have outdated content
