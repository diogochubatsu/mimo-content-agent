## Pin Design Guidelines

- **Format**: 1000x1500px (2:3 ratio) — optimal for Pinterest
- **Fonts**: Bold headline (Montserrat/Oswald), clean body (Open Sans)
- **Colors**: High contrast, use brand colors #FF0000 (red accent) + #1a1a1a (dark)
- **CTA**: Always include "Save this pin" or "Pin for later"
- **Alt Text**: Include primary keyword + description for SEO

## Posting Strategy

- Post 2-3 pins per day (staggered times: 8am, 12pm, 8pm EST)
- Use Rich Pins (Article type) for all links
- Create a dedicated board: "Import & Sourcing Tips"
- Repin to relevant group boards weekly
- Track pin performance monthly (saves, clicks, impressions)
