## Canadian Customs Overview

### Customs Clearance Process

| Step | Duration | Requirements |
|------|----------|--------------|
| 1. Document submission | 1-2 days | Commercial invoice, packing list |
| 2. Duty assessment | 1-3 days | HS code verification |
| 3. GST/HST calculation | 1 day | Value + duty |
| 4. Physical inspection | 1-5 days | Random selection |
| 5. Release | 1-2 days | Payment of duties/taxes |

## Duty Rates

### Canadian Duty Structure

| Product Category | HS Code | Duty Rate |
|------------------|---------|-----------|
| Electronics | 8517-8528 | 0-8% |
| Kitchen appliances | 8516 | 5-8% |
| Textiles/apparel | 6101-6211 | 16-18% |
| Toys | 9503 | 0-8% |
| Furniture | 9401-9406 | 0-9% |
| Beauty products | 3304-3305 | 0-6% |

### Duty Calculation

```
Duty = Declared Value (CAD) × Duty Rate
```

**Example:**
- Declared value: $20,000 CAD
- Duty rate: 8%
- Duty: $1,600 CAD

### Tariff Reduction

| Agreement | Benefit | Eligibility |
|-----------|---------|-------------|
| CPTPP | Reduced/eliminated duties | Member countries |
| CETA | Reduced duties | EU products |
| USMCA | Duty-free | US/Mexico products |

**Note:** China is NOT part of these agreements. Full duties apply.

## GST/HST Calculation

### GST/HST Rates by Province

| Province | Rate | Total Tax |
|----------|------|-----------|
| Alberta | 5% GST | 5% |
| British Columbia | 5% GST + 7% PST | 12% |
| Ontario | 13% HST | 13% |
| Quebec | 5% GST + 9.975% QST | 14.975% |
| Nova Scotia | 15% HST | 15% |

### GST/HST Calculation

```
GST/HST = (Declared Value + Duty) × Tax Rate
```

**Example (Ontario):**
- Declared value: $20,000 CAD
- Duty: $1,600 CAD
- HST (13%): ($20,000 + $1,600) × 0.13 = $2,808 CAD

## People Also Ask

1. **How do I import from China to Canada?** Find suppliers, verify, calculate landed costs, arrange shipping, clear customs. See our [How to Import From China](/how-to-import-from-china/) guide.

2. **What's the duty rate from China to Canada?** Varies by product: 0-18%. Average 5-15%. Check HS code for exact rate.

3. **Do I pay GST/HST on imports?** Yes, on declared value + duty. Rate varies by province (5-15%).

4. **How do I clear Canadian customs?** Submit documents, pay duties/taxes, pass inspection if selected. Use customs broker.

5. **What documents do I need?** Commercial invoice, packing list, bill of lading, certificate of origin (if applicable).

6. **How long does shipping take?** Sea freight: 30-40 days. Air freight: 5-8 days. Express: 3-5 days.

7. **What's the cheapest shipping method?** Sea freight FCL for bulk orders. LCL for smaller orders.

8. **Do I need a customs broker?** Recommended for first-time importers. They handle documentation and clearance.

9. **What products require special compliance?** Electronics (CSA), food (CFIA), cosmetics (Health Canada), children's products (CPSIA).

10. **How do I reduce duty costs?** Proper HS classification, trade agreements, duty drawback program, consolidation.
