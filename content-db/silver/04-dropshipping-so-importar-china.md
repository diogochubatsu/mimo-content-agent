## Executive Summary

O dropshipping da China permite vender produtos sem estoque, direto de fábricas chinesas. As principais plataformas são Alibaba (mais segura), 1688 (mais barata) e AliExpress (mais fácil). O tempo de entrega varia de 7-45 dias dependendo do método de frete. Margens típicas são 25-45% para produtos de consumo.

**Pontos-chave:**

- Alibaba: melhor para iniciantes (Trade Assurance)
- 1688: 15-25% mais barato que Alibaba (requer agente)
- AliExpress: melhor para testes e pedidos avulsos
- Tempo de entrega: 7-45 dias dependendo do método
- Margem típica: 25-45%

## Como Funciona o Dropshipping da China

### O Processo Completo

```
Cliente faz pedido → Você encaminha ao fornecedor → Fornecedor envia → Cliente recebe
```

### Fluxo Operacional Detalhado

1. **Cliente pede na sua loja** — Pagamento processado
2. **Você faz pedido no fornecedor** — Via plataforma ou agente
3. **Fornecedor separa e embala** — Geralmente 1-3 dias úteis
4. **Transportadora retira** — DHL, FedEx, ePacket, etc.
5. **Produto em trânsito** — 7-45 dias dependendo do método
6. **Cliente recebe** — Verifica e avalia

### Vantagens do Dropshipping da China

| Vantagem | Detalhes |
|----------|---------|
| Preço | 30-70% mais barato que varejo |
| Variedade | Milhões de produtos disponíveis |
| Escalabilidade | Sem limite de estoque |
| Flexibilidade | Testar produtos sem compromisso |
| Baixo investimento | R$ 500-2.000 para começar |

### Desafios Específicos

| Desafio | Solução |
|---------|---------|
| Tempo de entrega | Use warehouses locais ou fulfillment centers |
| Qualidade inconsistente | Peça amostras e inspecione |
| Barreira do idioma | Use agentes ou tradutores |
| Pagamento | Use plataformas seguras |
| Devoluções | Política clara + reembolso rápido |

## Logística e Entrega

### Métodos de Frete

| Método | Tempo | Custo | Rastreamento |
|--------|-------|-------|-------------|
| ePacket | 15-30 dias | Baixo | Sim |
| AliExpress Standard | 15-25 dias | Médio | Sim |
| DHL Express | 3-7 dias | Alto | Sim |
| FedEx | 3-7 dias | Alto | Sim |
| Frete Marítimo | 25-45 dias | Muito Baixo | Parcial |
| Frete Aéreo | 5-10 dias | Médio-Alto | Sim |

### Escolhendo o Método Certo

- **Para pedidos abaixo de R$ 100:** ePacket ou AliExpress Standard
- **Para pedidos de R$ 100-500:** DHL ou FedEx
- **Para volumes grandes:** Frete marítimo via freight forwarder
- **Para urgências:** DHL Express ou FedEx International Priority

### Customs e Despacho

Para evitar problemas na alfândega:
- Declare valor real (nunca subfature)
- Use HS code correto
- Para eletrônicos, verifique certificações ANATEL
- Considere usar fulfillment center no Brasil para evitar despacho individual

5. **Use moeda fixa** — Negocie preço em dólar

## Impostos e Regulamentação

### Impostos de Importação para Brasil

| Imposto | Alíquota | Base de Cálculo |
|---------|----------|-----------------|
| II (Imposto de Importação) | 0-35% | Valor aduaneiro |
| IPI | 0-300% | Preço de venda |
| PIS-Importação | 1,65% | Valor aduaneiro |
| COFINS-Importação | 7,6% | Valor aduaneiro |
| ICMS | 12-18% | (Valor aduaneiro + II + IPI) / (1 - ICMS) |

### Exemplo de Cálculo

Produto com FOB de R$ 50:
- II (16%): R$ 8,00
- IPI (15%): R$ 7,50
- PIS (1,65%): R$ 0,83
- COFINS (7,6%): R$ 3,80
- ICMS (18%): R$ 15,00
- **Total impostos: R$ 35,13 (70% do FOB)**

### Regulamentação

- **ANATEL:** Eletrônicos com wireless
- **INMETRO:** Produtos de segurança
- **ANVISA:** Cosméticos, alimentos, medicamentos
- **MAPA:** Produtos agrícolas, animais

## Margens e Precificação

### Fórmula de Precificação

```
Preço de Venda = (Custo Produto + Frete + Impustos + Fixos) × Markup
```

### Markup Recomendado

| Categoria | Markup | Margem Esperada |
|-----------|--------|----------------|
| Eletrônicos | 2,5-3,5x | 25-35% |
| Moda | 3-5x | 30-40% |
| Casa | 3-4x | 30-40% |
| Beleza | 4-6x | 35-45% |
| Brinquedos | 3-4x | 30-40% |

### Exemplo Prático

**Produto:** Fone bluetooth
- Custo FOB: R$ 25
- Frete: R$ 15
- Impostos: R$ 18
- Custo total: R$ 58
- Preço de venda: R$ 149,90
- **Margem: 41%**

### Erros Comuns de Precificação

1. **Não incluir todos os custos** — Esquecer frete, impostos, ou custos fixos
2. **Preço baixo demais** — Margem insuficiente para cobrir imprevistos
3. **Markup muito alto** — Preço acima do mercado, poucas vendas
4. **Não considerar CAC** — Custo de aquisição do cliente não incluído

## Erros Comuns no Dropshipping da China

### 1. Não Testar Amostras

**Consequência:** Produto chega diferente do esperado, devoluções altas
**Solução:** Sempre peça 2-3 amostras antes do pedido grande

### 2. Depender de Um Único Fornecedor

**Consequência:** Se o fornecedor falhar, seu negócio para
**Solução:** Tenha pelo menos 2-3 fornecedores backup

### 3. Subestimar Impostos

**Consequência:** Margem menor que o esperado
**Solução:** Calcule todos os impostos antes de precificar

### 4. Não Verificar Regulamentação

**Consequência:** Produto retido na alfândega
**Solução:** Pesquise exigências ANATEL, INMETRO, etc.

### 5. Ignorar Atendimento ao Cliente

**Consequência:** Reviews negativos, baixa conversão
**Solução:** Responda rápido, seja transparente, resolva problemas

### 6. Não Escalar com Dados

**Consequência:** Perde oportunidades de crescimento
**Solução:** Use analytics para identificar best-sellers e otimizar

## Frequently Asked Questions (FAQ)

### 1. Qual plataforma escolher para começar?

Comece com Alibaba (Trade Assurance protege). Depois migre para 1688 quando tiver volume.

### 2. Quanto tempo leva para chegar no Brasil?

ePacket: 15-30 dias. DHL/FedEx: 3-7 dias. Marítimo: 25-45 dias.

### 3. Como evitar ser enganado?

Use Trade Assurance, peça amostras, verifique o fornecedor, e nunca pague 100% antecipado.

### 4. Quais são os custos ocultos?

Impostos de importação (30-60% do FOB), frete, despachante aduaneiro, e eventuais taxas de armazenagem.

### 5. É possível lucrar com produtos baratos?

Sim, mas exige alto volume. Produtos de R$ 10-30 precisam de markup 4-5x para serem lucrativos.

### 6. Como lidar com devoluções?

Ofereça reembolso sem burocracia. Para pedidos acima de R$ 100, peça fotos do produto.

### 7. Precisa de MEI para começar?

Sim, para faturamento até R$ 81.000/ano. Acima disso, ME ou LTDA.

### 8. Como escolher o melhor frete?

Para pedidos pequenos: ePacket. Para urgentes: DHL. Para volumes: marítimo.

### 9. Quais produtos são proibidos?

Produtos sem registro ANATEL, armas, drogas, produtos químicos perigosos.

### 10. Como escalar o negócio?

Automatize pedidos, diversifique fornecedores, crie marca própria, e expanda canais.

### 11. Compensa usar agente?

Para 1688: sim. Para Alibaba: não necessário. O agente cobra 5-10% mas facilita o processo.

### 12. Como calcular a margem real?

Inclua todos os custos: produto, frete, impostos, plataforma, tráfego, e atendimento.
