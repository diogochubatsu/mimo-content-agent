# Importação Acessórios para Smartphones

Um ramo muito interessante para se explorar é o ramo de acessórios para celular. Este também é um daqueles que tem o giro mais baixo e a margem alta.

## Oportunidade de mercado

Considerando que tem mais celular que gente no Brasil, e essa é uma tendência mundial, vender acessórios para telefone celular ou smartphones apresenta-se uma oportunidade incrível.

Quem não tem ainda um smartphone com certeza terá, quem já tem as vezes pode ter até o segundo. Um para o trabalho e um para uso pessoal.

## Impulsionadores

Esse mercado é impulsionado por:
- Proteção
- Moda/design

## Evolução das margens

Anteriormente os acessórios apresentavam uma margem de lucro maior. Atualmente, o mercado está mais horizontal, apresentando muitos modelos para comprar o que atraiu mais fornecedores. No entanto ainda apresenta margens muito boas.

## Viabilidade

Essa é uma oportunidade que pode ser explorada mesmo a partir do Brasil. Se puder viajar para a China, é melhor, mas se não tem essa disponibilidade no momento, é possível começar à distância.
