# Importação da China para Dropshipping: Guia Completo

## Principais Plataformas

### AliExpress
A plataforma mais utilizada para dropshipping, oferecendo:
- Variedade enorme de produtos
- Avaliações detalhadas de fornecedores
- Proteção ao comprador
- Envio internacional

## Como Escolher Fornecedores Confiáveis

1. **Verificar avaliações** - Procure fornecedores com 4.5+ estrelas
2. **Tempo de operação** - Preferência para lojas com 2+ anos
3. **Quantidade de vendas** - Lojas com mais vendas são mais confiáveis
4. **Fotos reais** - Verifique se as fotos são autênticas
5. **Comunicação** - Fornecedores que respondem rapidamente

## Dicas Importantes

### Antes de Comprar
- Peça amostras para testar a qualidade
- Verifique os tempos de envio
- Leia as políticas de devolução
- Confirme se há estoque disponível

### Durante o Processo
- Mantenha comunicação com o fornecedor
- Acompanhe os códigos de rastreamento
- Documente qualquer problema

### Após a Entrega
- Solicite feedback do cliente
- Avalie o fornecedor
- Mantenha registros para análise

## Erros Comuns a Evitar

1. Não testar o produto antes de vender
2. Escolher fornecedores apenas pelo preço
3. Não verificar tempos de envio
4. Ignorar avaliações negativas
5. Não ter plano B para fornecedores
