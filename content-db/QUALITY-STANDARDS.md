
# Quality Standards

## Content Grading Rubric

### Grade A (Excellent)
- 2000+ words
- 3+ data tables
- Expert quotes
- FAQ section
- Internal links (3-5)
- Images/graphics
- SEO optimized
- Schema markup

### Grade B (Good)
- 1500-2000 words
- 1-2 data tables
- Some expert quotes
- Basic SEO
- 1-2 internal links

### Grade C (Needs Improvement)
- <1500 words
- No data tables
- No expert quotes
- Poor SEO
- No internal links

## Source Quality Standards

### Grade A (Excellent)
- All metadata fields present
- Recent data (<30 days old)
- From authoritative source
- Multiple data points

### Grade B (Good)
- Most metadata fields present
- Somewhat recent data
- Decent source quality

### Grade C (Needs Improvement)
- Missing metadata fields
- Old data (>30 days)
- Unknown source quality

## Article Quality Checklist

- [ ] Title includes primary keyword
- [ ] Article has 1500+ words
- [ ] Contains at least 2 data tables
- [ ] Has FAQ section
- [ ] Includes expert quotes
- [ ] Has internal links (3-5)
- [ ] Has image placeholder
- [ ] Meta description present
- [ ] Schema markup included
- [ ] Source citations present
