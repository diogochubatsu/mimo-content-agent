# How to Calculate Duties and Taxes on Imports to Germany

**Country:** Germany
**Currency:** Euro (€, EUR)
**Official Authority:** Generalzolldirektion (German Customs)

## Understanding Import Duties

Customs duties determined by the EU Common Customs Tariff (CCT):
- Duty rate based on product classification (HS Code → 8-digit CN → 10-digit TARIC)
- Country of origin critical for preferential rates under Free Trade Agreements
- Duty de minimis threshold: €150

## Calculation Steps

### 1. Determine Customs Value
- Start with transaction price
- Add freight and insurance costs up to EU border
- This is the dutiable value (CIF basis)

### 2. Classify Goods
- Identify correct 8-digit CN or 10-digit TARIC code
- Find applicable customs duty rate

### 3. Calculate Customs Duty
- Customs Value × duty rate
- If Customs Value ≤ €150, duty = €0

### 4. Calculate Import VAT (EUSt)
- VAT calculated on: Customs Value + Customs Duty + Domestic Charges
- Tax de minimis threshold: €0 for commercial goods (all imports subject to VAT)

## Example Scenarios

| Scenario | Customs Value | Duty | Import VAT |
|----------|--------------|------|------------|
| Low-value (€100) | €100 | €0 (below €150) | Due on full value |
| High-value (€500) | €500 | Calculated | Calculated on value + duty |
| IOSS B2C (€120) | €120 | €0 | Exempt at border (paid at sale) |

## Special Rules

- **IOSS (Import One Stop Shop)**: Simplifies VAT for B2C distance sales up to €150
- **CBAM (Carbon Border Adjustment Mechanism)**: New levy on carbon-intensive imports (cement, steel, aluminium) - transitional phase 2025, financial obligations from 2026

## Common Mistakes to Avoid

- Assuming old €22 VAT exemption is still valid (it's not)
- Using incorrect 6-digit HS code instead of required 8-digit CN
- Ignoring customs valuation rules (must include freight/insurance)
