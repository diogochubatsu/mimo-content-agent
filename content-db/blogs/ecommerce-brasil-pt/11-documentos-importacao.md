# Documentos para importação: tudo sobre as exigências legais

**Fonte:** E-Commerce Brasil

A importação de produtos para o Brasil exige uma série de documentos que devem estar em conformidade com as normas da Receita Federal. O principal documento é a nota fiscal de exportação emitida pelo fornecedor.

Outros documentos importantes incluem: known shipper (declaração do exportador), packing list detalhado, certificado de origem (quando aplicável) e licença de importação para produtos que exigem autorização de órgãos reguladores.

Para importações via marketplace, a plataforma geralmente se responsabiliza pela documentação. No entanto, o importador deve verificar se todos os documentos estão corretos para evitar problemas no desembaraço.

A regularidade fiscal do importador é essencial. Cadastro no RADAR (Registro e Rastreamento da Atuação dos Intervenientes Aduaneiros) é obrigatório para empresas que realizam importação regular.
